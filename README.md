# Personal Finance Dashboard

A demo **Full Stack Personal Finance Dashboard** designed to showcase data modeling, business logic, and financial data visualization using modern web technologies.

This project simulates a personal finance management platform, allowing users to register incomes and expenses, define category budgets, and visualize financial data through interactive dashboards.

---

## Overview

The Personal Finance Dashboard works like a smart spreadsheet, combining structured data storage, automated calculations, and visual insights.  
It was built as a **portfolio project** to demonstrate full stack development skills, with a strong focus on clarity, organization, and real-world logic.

---

## Features

- Add, edit, and delete income and expense transactions  
- Categorize financial records  
- Define monthly budgets per category  
- Automatically calculate balances and totals  
- Visualize data using charts and KPI cards  
- Filter transactions by date, category, and type  
- Demo data available for testing  
- Reset demo data functionality

## Project Scope & Decision

This project was intentionally designed as a **demo application**:

- Authentication was omitted to keep the focus on data modeling, calculations, and visualization  
- Data is not user-specific and may be reset periodically  
- The goal is to demonstrate technical skills rather than build a production-ready finance app  

These decisions help maintain a clean scope while highlighting core Full Stack competencies.
